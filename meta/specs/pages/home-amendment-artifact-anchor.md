## 3. Updated success criteria (delta against home.md §3)

The base spec's Behavior / Signal / Failure-mode framing carries over verbatim. A3 adds one positive dimension and two failure modes, and tightens one.

- **Felt anchor (new positive dimension):** A visitor scrolling past the Statement meets a **real object** — a genuine engineering artifact they recognize as actual work — and leaves thinking *"oh, they actually ship this."* The page reads as one authored object with two real visual moments (the leaned-in Hero glyph; the artifact), bracketing the recast exhibits below, rather than as one medium repeated. The variety is *distributed*, not front/back-loaded; the soft middle is gone because there is a real visual object in it.

- **Failure mode (new) — "the artifact is fake."** Any invented dashboard, fabricated metric inside the code, decorative terminal/browser chrome dressing it up as a screenshot, lorem-ipsum-with-syntax-highlighting, or a fragment pouk.ai cannot genuinely stand behind. This is the live instance of the §3 "the proof is fabricated" floor on the engineering-credibility axis — **the single worst way the A3 anchor can ship.** A fabricated artifact is worse than no artifact. Mitigated by the binding-realness AC (§6) and the no-fake fallback (§4.2).

- **Failure mode (new) — "the page became a dev-tool landing page."** Code on a marketing home page is a craft risk: done carelessly it reads as a developer-tool product page, not an engineer's confident front room. The mitigation is *minimalism and realness* — one small fragment, beautifully set, monochrome, on a recessed surface in the page's existing hand — never a wall of code, never an IDE-screenshot aesthetic, never rainbow syntax. If the artifact reads as "a code editor embed," the beat failed even if the code is real.

- **Tightened — "restraint reversed into volume."** A3 adds a beat and bigger type (the display number, the asymmetric lead discipline, the display-adjacent close). The strike must still come from *composition, scale, and one real object* — never from quantity of sections or louder chrome. Bigger type at one or two deliberate focal points is restraint applied with confidence; bigger type everywhere is the failure.

The base spec's other failure modes (generic SaaS landing page; fabricated metric/comparison; merged bands; buried conversion) all carry forward unchanged.

### 4.2 Artifact exhibit — placement, surface, realness, fallback (the central A3 move)

- **Placement:** between Statement (beat 3) and What-we-do (beat 5), as beat 4. This is the mid-page position the A2 Method removal left empty; the artifact is the engage peak that solves the soft-middle structurally (one new medium where the page sagged), which type-weight alone could not.
- **What it is:** ONE genuine, minimal engineering artifact — a real code / config / PR / architecture fragment with **true syntax that parses** and **true content pouk.ai can stand behind**, drawn from actual work or a true representative pattern. Short enough to read at a glance. It shows *how pouk.ai thinks* (the shape of a real integration, an automation's core, a config encoding a real decision), **not** a product feature.
- **Surface & register:** rendered SITE-SIDE as a real `<pre><code>` block on a DS recessed surface (`--surface-section` / DS recessed tokens), Geist Mono, **monochrome** — emphasis via weight / italic / opacity only, **the accent never at rest, no rainbow syntax theme.** It reads as engraved code, not an IDE screenshot. Same hand as the glyph (hairline + mono). **No DS code/artifact primitive exists** (A3 §30 — confirmed real DS gap); ship site-side, do NOT spec a new DS component (see §7 awareness-only flag).
- **Surface vs. band-count reconciliation (designer + engineer):** the two-band floor (Why-us + Convert) is unchanged. The artifact's recessed/inset surface must read as **a framed exhibit object, not a third full-bleed `--surface-section` band** — i.e. it is an inset/object surface within the `--bg` flow, distinct in register from the two full bands so the page does not read as three banded slabs. The designer owns making the artifact surface legible-as-object without it counting as (or reading as) a third band; if at composition review the only way to frame the artifact is a third full band, that is escalated to Arian (it conflicts with the §16 floor) rather than shipped silently. Default: inset object surface on `--bg`, not a full band.
- **BINDING realness gate (hard, non-negotiable — see AC §6):** the artifact must be genuinely real. **No invented dashboards, no fake metrics in the code, no decorative terminal/browser chrome, no lorem-ipsum-with-syntax-highlighting.** Content sources genuine publishable candidates; **Arian confirms one before build.**
- **No-fake fallback (binding):** if no real, publishable fragment can be sourced (confidentiality, or nothing representative is shippable), **the artifact beat does NOT ship a fabricated stand-in.** The page falls back to a non-artifact treatment of the mid-page slot — the designer's options, in priority order: (i) **strengthen the asymmetric What-we-do beat** to carry the mid-page weight (the A2 §15 Disciplines-weight lever, now the primary fallback), and accept a leaner top-and-tail-weighted page (direction §24 (c) honest ceiling for the middle); (ii) the mid-page slot stays `--bg` type only. **No fabricated artifact, no eagle substitute (D-17 closed), no second illustration vocabulary.** This is the same posture as the cited-metric "no number → no mark": **no real fragment → no artifact beat.**

### 4.3 Hero glyph — lean in (craft only)

- The glyph is the page's already-real visual object and strongest asset; A3 §28 directs **leaning in**: it may be made **bigger and/or more crafted** — more presence, finer hairline detail, more deliberate composition in the Hero's right column — so it reads unmistakably as a *signature*, not a small decorative diagram.
- **No content change.** The OBSERVE→SHIP labels, the caption, and the CSS signal-pulse are unchanged (A2 §14). "Leaning in" is scale/craft for the designer, not animation (the pulse is the only glyph motion; no new motion, no draw-on). The glyph and the artifact are the same hand (hairline + mono, monochrome) — the page reads as one authored object with two real visual moments.

### 4.4 What we do — asymmetric (recast)

- Recast from the A2 3-equal `FeatureGrid` to an **asymmetric** layout: a **lead discipline + two** (or 2+1) — one of builds / automations / advisory carries more weight (scale, span, position), the other two subordinate. This gives the beat an internal focal point and a composed rhythm instead of three identical columns (the 3-equal grid is itself a mild SaaS tell).
- Still **transparent, icon-less, honest one-sentence bodies** — designed, not gridded. The anti-slop guardrail binds: no decorative/vibe icons, no three-word feature headlines, no gradient cards, no equal-weight filler. The DS vehicle (an asymmetric composition of `FeatureCard`/`Section`/editorial blocks) is the designer's call; this spec fixes only that the layout is asymmetric, transparent, and honest. On `--bg`.
- **Which discipline leads is a content/Arian call** (see §5), not a layout default — the lead should be the discipline pouk.ai most wants the operator to map their problem to. Schema gains an optional lead-marker (§5).

### 4.5 Why us — table → exhibit (recast)

- **The number is the section hero.** The **MIT NANDA**-cited deployment-gap figure renders at **true display scale** — the biggest single number on the page, the eye's first stop in the beat, NOT a caption above a table.
- **The honest cut becomes a tighter 2-axis layout, not a 4-column grid:** recast as **pouk.ai vs. the alternatives** — a sparser, more legible opposition (one axis the alternatives, one axis the honest dimensions) — fewer cells, bigger type, more air.
- **Negative space + sparse structural dividers replace per-row hairlines.** Rhythm from whitespace and at most a few dividers, not a hairline on every row (the per-row hairline is the "spec-sheet / doc" tell the audit named).
- **Fewer words, bigger type** — the comparison reads as a *stance* (the honest cut), not a reference table.
- **Honesty guardrail still binds (hard):** pouk.ai must NOT win every axis; at least one position must concede a competitor is the right call in some situation. **No "featured pouk.ai column" styling** that re-tilts candor through visual weight — the 2-axis form makes this risk sharper (a lone "us" axis is easy to over-emphasize) and the AC guards it (§6).
- **The MIT NANDA citation is binding and unchanged in requirement** (A2 §17): a real, attributable, published figure with **visible mono-register micro-caption stating source ("MIT NANDA") + year** — not a hidden footnote/tooltip. **No real attributable figure → no display number / no metric line, and the exhibit is the 2-axis honest cut alone.** Fabrication / unsupported rounding / anonymous "industry" numbers remain banned. Stays on recessed band #1. Ends with the inline `/why-ai` link; this beat is a *compression* of `/why-ai`'s vs-alternatives, never a reproduction.

### 4.6 Convert — designed typographic close (recast)

- Recast from a plain recessed band carrying type to an **authored editorial moment**: the closing line is the page's **last serif beat at display-adjacent scale**, deliberately composed — the Statement's louder sibling, so the page *closes* rather than just ends. Not a heading + two buttons on a tint.
